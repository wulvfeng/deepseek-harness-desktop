# DeepSeek Harness Desktop

> 🖥️ 一个基于 PyQt6 WebEngine 的桌面浏览器壳，**任何网页都可以放入运行**。  
> 默认加载 DeepSeek Harness Web 界面，也可以通过设置切换为任意网页地址。

---

## ✨ 特性

- 🌐 **通用网页壳** — 支持加载任意 URL / IP+端口 / 本地项目，适配任何 Web 应用
- 🚀 **默认 DeepSeek Harness** — 开箱即用，启动即加载 DeepSeek Harness 界面
- 📦 **三种来源模式** — 直接网址、IP+端口、本地启动（静态目录 / npm run dev）
- 🎨 **现代 UI 主题** — 内置 Indigo 风格 QSS 主题，深色终端日志面板
- ⌨️ **F12 开发者日志** — 按 F12 展开/收起命令日志面板（类似浏览器 DevTools）
- 🔄 **智能就绪检测** — 命令启动模式下自动探测服务就绪，支持自动识别 URL
- 🌍 **局域网地址** — 自动检测并显示局域网访问地址，方便手机等设备调试
- 💾 **SQLite 配置持久化** — 所有设置自动保存，重启后自动恢复
- 🖼️ **窗口记忆** — 关闭时记住窗口大小，下次启动自动恢复
- 📐 **高 DPI 支持** — 原生支持高分屏，界面清晰不模糊

## 🚀 快速开始

### 环境要求

- Python >= 3.11
- pip 或 [uv](https://github.com/astral-sh/uv)（推荐）

### 安装依赖

```bash
# 方式一：使用 uv（推荐）
uv sync

# 方式二：使用 pip
pip install -r requirements.txt
```

### 启动应用

```bash
python main.py
```

启动后会自动加载配置中保存的网页来源，默认为 DeepSeek Harness Web 界面。

> 💡 **首次使用**：如果默认 URL 无法访问，请点击工具栏「设置」按钮配置正确的地址。

## ⚙️ 配置说明

点击工具栏右侧的 **「设置」** 按钮打开配置面板。支持三种网页来源模式：

### 模式一：直接网址 (URL)

最简单的模式，直接输入任何网页地址。

| 字段 | 说明 | 示例 |
|------|------|------|
| 网址 | 目标网页完整 URL | `https://www.example.com` |

**典型用途**：
- 加载 DeepSeek Harness：`http://127.0.0.1:3080`
- 加载任何在线 Web 应用

### 模式二：IP + 端口

通过 IP 地址和端口号拼接为 `http://ip:port` 访问。

| 字段 | 说明 | 示例 |
|------|------|------|
| IP | 服务器 IP 地址 | `127.0.0.1` |
| 端口 | 服务端口号 | `8000` |

**典型用途**：
- 访问已在运行的本地服务
- 访问局域网内其他机器的服务

### 模式三：本地启动

自动启动本地服务后再加载页面，分为两种子模式：

#### 📂 静态文件目录

将指定文件夹作为静态站点启动 HTTP 服务。

| 字段 | 说明 | 示例 |
|------|------|------|
| 静态目录 | 包含 HTML/CSS/JS 的文件夹 | `./dist` |
| 服务端口 | HTTP 服务监听端口 | `8000` |

**典型用途**：
- 加载前端构建产物（`dist/`、`build/`）
- 加载任意静态 HTML 页面

#### ⚡ 命令启动

在指定目录执行命令（如 `npm run dev`），等待服务就绪后自动加载。

| 字段 | 说明 | 示例 |
|------|------|------|
| 项目目录 | 命令执行的工作目录 | `./my-vue-app` |
| 启动命令 | 要执行的命令 | `npm run dev` |
| 就绪后加载 | 服务就绪后访问的 URL（留空自动识别） | `http://127.0.0.1:5173` |
| 就绪超时 | 等待服务启动的最大秒数 | `60` 秒 |

**典型用途**：
- 启动 Vite / Vue / React 开发服务器
- 启动任何本地开发环境

> 💡 **自动识别**：「就绪后加载」留空时，应用会自动从命令输出中识别 URL（如 Vite 打印的 `Local: http://localhost:5173/`）。

### 窗口外观

| 字段 | 说明 |
|------|------|
| 窗口标题 | 自定义窗口标题 |
| 窗口图标 | 选择 .png / .ico 图标文件 |

## 💡 使用场景示例

### 场景 1：作为 DeepSeek Harness 桌面客户端

1. 确保 DeepSeek Harness Web 服务已在 `http://127.0.0.1:3080` 运行
2. 启动本应用，默认即加载该地址
3. 获得独立的桌面客户端体验

### 场景 2：包装前端项目为桌面应用

1. 设置 → 本地启动 → 命令启动
2. 项目目录填前端项目路径
3. 启动命令填 `npm run dev`
4. 留空「就绪后加载」，应用会自动识别 Vite/Webpack 的端口

### 场景 3：为静态 HTML 页面创建桌面入口

1. 设置 → 本地启动 → 静态文件目录
2. 选择包含 HTML 文件的文件夹
3. 设置端口号，保存即可

### 场景 4：访问局域网内其他设备的服务

1. 设置 → IP + 端口
2. 输入目标设备 IP 和端口
3. 日志面板会自动显示局域网访问地址，方便手机同步调试

## 📝 配置存储

所有配置保存在项目根目录的 `config.db`（SQLite 数据库）中，无需手动编辑配置文件。

如需重置配置，删除 `config.db` 文件后重启应用即可恢复默认设置。

> ⚠️ `config.db` 已在 `.gitignore` 中排除，不会被提交到版本控制。
